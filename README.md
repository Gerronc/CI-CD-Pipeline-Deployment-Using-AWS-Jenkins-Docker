# CI-CD-Pipeline-Deployment-Using-AWS-Jenkins-Docker

I designed and built a fully automated CI/CD pipeline to deploy a containerized web application using modern DevOps tools and cloud infrastructure.

🧰 Technologies Used
	•	Amazon Web Services (EC2)
	•	Jenkins
	•	Docker
	•	GitHub
	•	Docker Hub

🏗️ How It Works

This pipeline automates the entire deployment process:

1️⃣ Code is pushed to GitHub
2️⃣ A webhook triggers Jenkins automatically
3️⃣ Jenkins executes a pipeline (Jenkinsfile)
4️⃣ A Docker image is built and pushed to Docker Hub
5️⃣ The application is deployed on AWS EC2
6️⃣ The web app becomes publicly accessible

⚙️ Key Features

✔️ Fully automated CI/CD pipeline
✔️ Webhook-triggered builds (no manual steps)
✔️ Containerized deployment using Docker
✔️ Cloud hosting on AWS EC2
✔️ Version-controlled pipeline configuration

🧠 What I Learned
	•	How CI/CD supports the Software Development Lifecycle
	•	Hands-on experience with Jenkins pipelines and automation
	•	Containerization and deployment using Docker
	•	Integrating GitHub webhooks with Jenkins
	•	Deploying and managing applications in the cloud

🔐 Security Considerations
	•	Configured AWS EC2 security groups to restrict access
	•	Exposed only required ports (SSH, HTTP, Jenkins)
	•	Used containerization to isolate the application environment
